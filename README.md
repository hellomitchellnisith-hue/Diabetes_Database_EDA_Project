# 🩺 Diabetes EDA Project Using Python

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) of a diabetes dataset using Python. It explores health-related factors such as glucose, BMI, blood pressure, insulin, age, and pregnancies to identify patterns and understand their association with diabetes outcomes.

## 🎯 Objectives
- Understand the structure and characteristics of the dataset.
- Identify potential missing values and data-quality issues.
- Clean the dataset using appropriate preprocessing techniques.
- Analyze diabetic and non-diabetic outcome distributions.
- Visualize relationships and distributions among health-related variables.
- Generate meaningful insights through data analysis.

## 📂 Dataset Information
- **Dataset:** Diabetes Dataset
- **Total Records:** 768
- **Total Columns:** 9
- **Target Variable:** `Outcome`
- **Outcome 0:** Non-diabetic
- **Outcome 1:** Diabetic

### Features
- `Pregnancies` — Number of pregnancies
- `Glucose` — Plasma glucose concentration
- `BloodPressure` — Diastolic blood pressure
- `SkinThickness` — Triceps skinfold thickness
- `Insulin` — Insulin level
- `BMI` — Body Mass Index
- `DiabetesPedigreeFunction` — Family-history-related diabetes risk indicator
- `Age` — Age of the individual
- `Outcome` — Diabetes classification

## 🛠️ Tools & Technologies
- **Python** — Data analysis and programming
- **Jupyter Notebook** — Interactive analysis
- **Pandas** — Data manipulation and cleaning
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization

## 🔍 Project Workflow
1. Imported the required Python libraries.
2. Loaded and inspected the dataset.
3. Checked dataset dimensions, data types, null values, and duplicate records.
4. Identified zero values that may represent missing health measurements.
5. Replaced selected zero values with `NaN` in the cleaned dataset.
6. Applied median imputation to handle missing values.
7. Analyzed the distribution of diabetes outcomes.
8. Created visualizations to explore health-related patterns.
9. Summarized key findings and analytical insights.

## 📊 Data Visualizations
### 1. Age vs Average Glucose Level — Line Plot
Explores variations in average glucose levels across different age groups.

### 2. Glucose vs BMI — Scatter Plot
Examines the relationship between glucose levels and BMI, with diabetes outcomes represented using different colors and age represented by point size.

### 3. Average Blood Pressure and Insulin — Bar Plot
Compares average blood pressure and insulin levels between diabetic and non-diabetic groups.

### 4. Glucose Distribution — Histogram
Displays the frequency distribution of glucose measurements and helps identify common value ranges.

## 💡 Key Insights
- The dataset contains 768 records and 9 columns.
- The non-diabetic group contains 500 individuals (65.10%), while the diabetic group contains 268 individuals (34.90%).
- Zero values were identified in several health-related features and investigated as potential missing measurements.
